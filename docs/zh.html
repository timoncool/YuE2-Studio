功能

可编辑的乐谱

作品以 ABC 记谱法返回并排版为五线谱。

翻唱

SheetSage2 把录音的旋律记成乐谱，YuE2 用你的风格演唱。

任意音轨转 MIDI

歌曲、分轨或处理后的版本都能在你的显卡上由 MuScriptor 转为多乐器 MIDI——34 个乐器组加鼓。

训练你自己的 LoRA

用同一歌手或风格的歌曲，在你的显卡上以 HOT-Step 的训练器和配方训练 LoRA。

每首曲目都有封面

没有封面的曲目会得到符合其风格的 Wikimedia Commons 免费 CC0 照片、21 种样式之一的图案，或通过 OpenRouter 生成的封面。

由你的智能体操控（MCP）

连接 Claude Code、Claude Desktop 或 Cursor，智能体就能做工作室能做的一切：写歌并生成、整理数据集并训练、绘制封面、在视频编辑器里剪辑 MV、播放歌曲——还能看到窗口并点击按钮。

常见问题

需要什么显卡？

Windows 10/11 x64，显存 6 GB 以上的显卡：NVIDIA（GTX 900 或更新）使用 CUDA；AMD 和 Intel 通过 Vulkan 运行，属实验性质。模型在工作室内按你的决定下载。

可运行的模型组由 YuE2-3B 主干和 VAE 组成；SheetSage2 可选，仅翻唱需要。

你的显卡模型组下载
12 GB+完整原生 — BF16，原始权重9.7 GB
8 GB+高质量 — Q8_0，接近无损4.9 GB
7 GB+均衡 — Q6_K4.0 GB
5.5 GB+轻量 — Q5_K_M3.6 GB

大小已包含 SheetSage2。工作室会预选你的显卡能运行的模型组，但是否下载始终由你决定。每个文件都按固定的 Hugging Face 版本校验 SHA-256，中断的下载可以续传。

免费吗？

是的。工作室免费且开源，模型也可以在其中免费下载。

没有网络能用吗？我的音乐会被上传吗？

你的音乐属于你，并留在你的磁盘上。

  • 无需账号 — 没有任何需要注册的东西。
  • 无遥测 — 工作室不会报告你生成了什么。
  • 云端需主动开启 — 在你添加密钥之前，没有任何数据离开电脑，之后也只用于对应功能。
生成的歌曲可以使用吗？

工作室和 yue2.cpp 采用 MIT 许可。YuE2-3B 与 YuE2 VAE 权重采用 CC BY-NC 4.0，并附个人创作者许可：以个人身份创作的音乐人和创作者可以出售并变现所制作的歌曲；公司需向作者取得许可。用于翻唱的 SheetSage2 采用 CC BY-NC 4.0。

能用我自己的风格训练吗？

用同一歌手或风格的歌曲，在你的显卡上以 HOT-Step 的训练器和配方训练 LoRA。每项设置都可修改，数据集可在本工作室与 MiniMax Music3 Studio 之间迁移。

AI 智能体能操作它吗？

连接 Claude Code、Claude Desktop 或 Cursor，智能体就能做工作室能做的一切：写歌并生成、整理数据集并训练、绘制封面、在视频编辑器里剪辑 MV、播放歌曲——还能看到窗口并点击按钮。模型的写作规则随之提供，风格和歌词由智能体自己来写。把它选为写作助手，就由它代替本地模型写词。

安装包里有什么？

默认全部本地运行。云端密钥由你添加，只用于你选择的功能。

它是如何构建的？

服务编译进桌面程序并管理 C++ 引擎。完成的歌曲由服务自己导入，因此刷新或关闭窗口也不会丢失结果。

React UI ─┐
          ├─ YuE2-Studio.exe   (Tauri window + Rust/Axum service)
Rust axum ┘        │
                   └─ yue2.cpp `yue-server`   (C++/CUDA, GGUF)
