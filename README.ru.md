# YuE2 Studio

[English](README.md) · **Русский** · [中文](README.zh.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Português](README.pt.md)

YuE2, ACE-Step и MiniMax в одной музыкальной студии. Переносите треки и плейлисты, сравнивайте дубли и пробуйте другие голоса через RVC.

[Скачать YuE2 Studio](https://github.com/timoncool/YuE2-Studio/releases/latest) · [Сайт проекта](https://timoncool.github.io/YuE2-Studio/ru.html) · [Поддержать проект](DONATE.ru.md)

## Первая песня

Возьмите установщик или портативный архив для Windows, DMG для macOS либо DEB/AppImage для Linux. При первом запуске установите предложенные компоненты и веса выбранной модели.

Откройте **Создать**, выберите YuE2 и установленный профиль, задайте стиль и текст или загрузите пример. Нажмите **Создать** и откройте готовую песню в разделе **Медиатека**.

## Перенос библиотеки

Откройте **Медиатека → Импорт → Библиотека ACE-Step или MiniMax**. Выберите найденную библиотеку ACE-Step Studio или MiniMax Music3 Studio либо нажмите **Выбрать папку старой студии**. Проверьте содержимое и свободное место, затем нажмите **Скопировать библиотеку в YuE2**. Исходная библиотека остаётся на месте.
