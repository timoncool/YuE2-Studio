# YuE2 Studio

[English](README.md) · [Русский](README.ru.md) · [中文](README.zh.md) · **日本語** · [한국어](README.ko.md) · [Português](README.pt.md)

YuE2、ACE-Step、MiniMax をひとつの音楽スタジオで。曲とプレイリストを取り込み、テイクを聴き比べ、RVC で別の歌声を試せます。

[YuE2 Studio をダウンロード](https://github.com/timoncool/YuE2-Studio/releases/latest) · [プロジェクトサイト](https://timoncool.github.io/YuE2-Studio/ja.html) · [プロジェクトを支援](DONATE.ja.md)

## 最初の曲を作る

Windows ではインストーラーまたはポータブル版、macOS では DMG、Linux では DEB または AppImage を選びます。初回起動時に、選択したモデルに必要なコンポーネントと重みをインストールします。

**作成** を開き、YuE2 とインストール済みのプロファイルを選びます。スタイルと歌詞を入力するか、サンプルを読み込みます。**作成** を押すと、完成した曲を **ライブラリ** で再生できます。

## ライブラリを移行する

**ライブラリ → インポート → ACE-Step または MiniMax のライブラリ** を開きます。検出された ACE-Step Studio または MiniMax Music3 Studio のライブラリを選ぶか、**以前の Studio のフォルダーを選択** を押します。プレビューと必要な空き容量を確認し、**YuE2 にライブラリをコピー** を押します。元のライブラリはそのまま残ります。
