# YuE2 Studio

[English](README.md) · [Русский](README.ru.md) · **中文** · [日本語](README.ja.md) · [한국어](README.ko.md) · [Português](README.pt.md)

在同一款音乐工作室中使用 YuE2、ACE-Step 和 MiniMax。导入曲目和播放列表，比较不同版本，并通过 RVC 尝试其他音色。

[下载 YuE2 Studio](https://github.com/timoncool/YuE2-Studio/releases/latest) · [项目网站](https://timoncool.github.io/YuE2-Studio/zh.html) · [支持项目](DONATE.zh.md)

## 制作第一首歌

Windows 可选安装程序或便携版，macOS 使用 DMG，Linux 使用 DEB 或 AppImage。首次启动时，安装所选模型需要的组件和权重。

打开 **创作**，选择 YuE2 和已安装的模型配置，输入风格和歌词，或载入示例。点击 **创作**，然后在 **音乐库** 中播放成品。

## 迁移曲库

打开 **音乐库 → 导入 → ACE-Step 或 MiniMax 曲库**。选择已找到的 ACE-Step Studio 或 MiniMax Music3 Studio 曲库，或点击 **选择旧版 Studio 文件夹**。检查预览和所需空间后，点击 **将曲库复制到 YuE2**。原曲库仍保留在原处。
